# 书写、协作与AI

## 直接触摸白板

单指写画；双指捏合放大缩小；三指拖动画布；四指向右滑上一页、向左滑下一页。一次滑动只翻一页，抬起手指后可再翻。鼠标用户可使用界面上的缩放和分页按钮。最低缩放5%；纪要、行动项等AI卡片随白板一起缩放和平移。页面列表中的红色删除按钮可直接点击，最后一页会保留。

## 摄像头食指书写

在画笔工具栏末尾、清空按钮下方点击摄像头开启食指书写，也可在设置中开启，首次允许摄像头访问。摄像头画面先出现，识别模型首次加载需要联网等待。伸出食指书写，收指停笔；预览可以收起，识别保持运行。点击停止才释放摄像头。识别在设备本地运行，不上传摄像头视频。

## AI整理和语音

打开左下角AI助手，选择脑图、会议纪要、行动项或建议，AI将读取白板文字、图片和图形。对话中输入指令继续整理，结果可输出到白板。麦克风功能需设备和浏览器支持，并需允许录音。无法确认的内容应人工复核。

## 分享与协作

右上角纸飞机把白板完整图片发送到已配置的群。飞书图片投递需要管理员配置应用凭证和群机器人；普通账号最多每分钟发送一次。

在设置→通用的“账号与协作”区域登录、查看保存状态、开通会员或打开多人协作。协作入口可生成同一块白板的链接。对方登录后打开同一链接，共同编辑。请只把协作链接分享给预期参与者。
