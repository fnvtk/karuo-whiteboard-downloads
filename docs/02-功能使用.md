# 书写、协作与AI

## 直接触摸白板

单指写画；双指捏合放大缩小；三指拖动画布；四指向右滑上一页、向左滑下一页。一次滑动只翻一页，抬起手指后可再翻。鼠标用户可使用界面上的缩放和分页按钮。画笔工具栏收起后，默认显示在右侧缩放按钮上方，按住图标可拖动；展开后的面板位置固定。最低缩放5%；纪要、行动项等AI卡片随白板一起缩放和平移。页面列表中的红色删除按钮可直接点击，最后一页会保留。

## 摄像头隔空书写

手机工具栏默认显示五项，前三项固定为选择、画笔、橡皮擦，其余按本机历史使用频率排序，左右滑动可找到其他工具；排序在重新展开时更新。平时只显示图标，按住才显示工具名称。点击摄像头“隔空书写”开启，也可在设置中开启，首次允许摄像头访问。默认后台加载，不弹出画面或缩小提示窗。设置→隔空书写可开启“显示摄像头预览”，隐藏画面仍继续书写。识别模型首次加载需要联网等待。伸出食指直接写，收起时停笔；隐藏预览后识别保持运行。点击停止才释放摄像头。识别在设备本地运行，不上传摄像头视频。

## AI整理和语音

打开左下角AI助手，选择脑图、会议纪要、行动项或建议，工具分析会读取白板文字、图片和图形；普通聊天直接回答问题，仅明确询问白板内容时读取白板。对话中输入指令继续整理，回复完成后才显示“将本次结果整理到白板”，点击后按标题和列表排版。对话历史按账号保存在当前浏览器，刷新后保留（最多100条），不会在普通聊天时自动写入白板。麦克风功能需设备和浏览器支持，并需允许录音。无法确认的内容应人工复核。

## 分享与协作

右上角纸飞机把白板完整图片发送到已配置的群。飞书图片投递需要管理员配置应用凭证和群机器人；普通账号最多每分钟发送一次。

月亮/白板底色位于设置→通用。打开链接先显示本地画布，已有账号和房间在后台恢复；云端功能仍需相应账号权限。在设置→通用的“账号与协作”区域登录、查看保存状态、开通会员或打开多人协作。协作入口可生成同一块白板的链接。对方登录后打开同一链接，共同编辑。请只把协作链接分享给预期参与者。


## 手机弹层、图片和全屏

- 右上角仍只有一个全屏图标。点击后，下方选择“放大全屏”或“隐藏工具并全屏”。
- 隐藏工具后，在白板空白区域同时用五根手指滑动，可显示工具；再次五指滑动可隐藏。在设置“通用”中可关闭这项手指操作。电脑可按 Esc 恢复工具。
- 手机浏览器若不提供网页全屏接口，白板会使用当前页面区域展示；浏览器自身的地址栏由浏览器管理。
- 点击“插入”图标，选择“图片”或“拍照”。照片会作为白板内容保存；在选择工具下点中图片，可使用“保存照片”。
- 点击“插入”图标里的“插入网址”，填写网站地址即可生成 iframe 网站卡片；无需输入 https://，会自动补全。拖动卡片顶部左侧手柄可移动卡片。网页卡片不提供跳转到浏览器的入口。
- 登录后后台恢复当前账号保存的私人白板和最近协作房间；原协作链接优先。恢复不同白板前，本机草稿会先保存在历史会话中。

图片、拍照、网址默认聚合在“插入”图标中，点击展开三项。插入完成后返回白板编辑，保留工具栏显示。


## 工具栏组合

选择、画笔、橡皮擦固定在前三位。默认将其余工具收为插入、绘制、样式、撤销重做、更多五个模块；手机默认显示五个图标，可横滑查看其余模块。

在“设置 → 工具栏”中，每个模块可选“合并图标”“独立图标”或“隐藏模块”。修改立即生效，保存在当前浏览器；可恢复默认组合。插入包含图片、拍照、网址，绘制包含文字、图形、表情，样式包含颜色与粗细，更多包含隔空书写与清空。

网页卡片顶部网址为只读文字，不会跳转或弹出浏览器窗口；长按顶部栏或边框约半秒，弹出元素菜单，可删除、调整层级。图片、贴纸、文字也支持同样长按操作；拖动超过小范围会取消长按菜单，避免误操作。网页自身的登录与访问权限仍由原网站管理。
