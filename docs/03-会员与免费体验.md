# 会员与免费体验

套餐均含相同会员功能，区别为使用时长：

| 套餐 | 价格 | 时长 |
|---|---:|---|
| 月卡 | ¥19.8 | 1个月 |
| 年卡 | ¥198 | 12个月 |
| 五年卡 | ¥598 | 60个月 |

不提供终身卡，不自动续费。在白板中打开“会员套餐”，选择套餐后使用手机微信扫码付款。付款成功后自动开通，以账号中的有效期为准。

免费体验按账号分别保存：AI总结10次、群分享10次、摄像头隔空书写10次，各用各的额度。总结和分享失败不扣次数；隔空书写成功启动识别算一次，关闭再开算下一次，摄像头或模型启动失败不扣次数。

免费版在同一块白板的全部页面合计可同时放1个网址，删除后可更换；插入第二个会弹出会员窗口。会员可添加多个网页。会员到期后已有网页保留，仍可查看、输入、拉长和删除，新增网页按免费容量执行。

| 功能 | 免费版 | 会员期内 |
|---|---|---|
| 基础画笔、文字、图片、触屏操作 | 免费 | 免费 |
| 嵌入网页 | 每块白板同时1个，删除后可换 | 可添加多个 |
| AI脑图、纪要、行动项、建议 | 共享10次体验 | 持续使用 |
| 群内分享 | 成功发送共10次 | 持续使用；普通账号每分钟最多1次 |
| 隔空书写 | 成功启动共10次，失败不扣 | 持续使用 |
| AI与语音对话 | 需会员 | 解锁 |
| 多人协作 | 需会员 | 解锁 |

价格与每项权益可在插入网址窗口及会员套餐中展开查看；三档套餐权益相同，只有有效期不同。

只通过应用内生成的微信支付码购买，不要向个人收款码转账。二维码20分钟有效；状态会自动更新，未付款不会开通。付款后未及时开通，请保留订单记录并联系管理员，不要重复付款。
