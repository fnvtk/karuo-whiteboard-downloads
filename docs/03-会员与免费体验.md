# 会员与免费体验

套餐均含相同会员功能，区别为使用时长：

| 套餐 | 价格 | 时长 |
|---|---:|---|
| 月卡 | ¥19.8 | 1个月 |
| 年卡 | ¥198 | 12个月 |
| 五年卡 | ¥598 | 60个月 |

不提供终身卡，不自动续费。在白板中打开“会员套餐”，选择套餐后使用手机微信扫码付款。付款成功后自动开通，以账号中的有效期为准。

免费体验按账号分别保存：AI总结10次、群分享10次、摄像头食指书写10次，各用各的额度。总结和分享失败不扣次数；食指书写成功启动识别算一次，关闭再开算下一次，摄像头或模型启动失败不扣次数。

会员功能包含AI总结、AI语音对话、群分享、多人协作和摄像头食指书写。基础画笔、文字、图片、触屏缩放移动翻页不依赖会员。

只通过应用内生成的微信支付码购买，不要向个人收款码转账。二维码20分钟有效；状态会自动更新，未付款不会开通。付款后未及时开通，请保留订单记录并联系管理员，不要重复付款。
