# 常见问题与卸载

**Windows 没有浏览器怎么办？** 安装 Edge 或 Chrome 后重新执行命令。Windows安装入口不会安装本地服务器。

**打不开白板？** 检查网络和系统时间，再访问 https://wz_wb.quwanzhi.com/ 。会议数据需要重要时请提前导出备份。

**摄像头无法开启？** 把白板切到前台，连接摄像头，允许访问，并关闭占用摄像头的其他应用。电视需配备可用摄像头；食指识别对光照和设备性能有要求。

**飞书群没收到图片？** 请管理员检查分享配置。Webhook地址和飞书应用凭证不是同一个东西。普通账号重复发送需等一分钟。

**会员购买按钮不可用？** 当前自动收款通道尚未开通，预览版不收款。

**Windows卸载？** 在PowerShell执行：

```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/fnvtk/karuo-whiteboard-downloads/main/install.ps1))) -Uninstall
```

这只删除本产品快捷方式和安装记录，浏览器中的账号和会议数据需要你自行决定是否保留。Android电视在系统应用设置中卸载“卡若智能白板”。
